# Rerun Notes

The scripts are copied from the validated Project 5 evidence route. They expect the package/project root to contain:

- `data/tum_dlo_dataset/m1690303/` for the TUM dataset.
- WireSeg data or the retained WireSeg sample metadata, depending on the script being run.
- `code/fastdlo_src/fastdlo-master/` for FASTDLO source code.
- `code/fastdlo_src/fastdlo-master/weights/` for FASTDLO weights.

Large raw data, third-party weights and generated checkpoints are intentionally excluded from GitHub. Use `DATASET_LINKS.md` to restore the external resources locally if a full rerun is required.
